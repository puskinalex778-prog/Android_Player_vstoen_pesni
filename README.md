# Е-Телевизёр — IPTV плеер для Android TV и смартфонов

**Е-Телевизёр** — полнофункциональный Android IPTV-плеер (аналог Televizo), созданный одновременно для **телевизоров / ТВ-приставок (Android TV, Google TV, AOSP TV Box с пультом ДУ)** и **смартфонов / планшетов Android**.

> Приложение является чистым медиаплеером и не содержит платного контента — вы подключаете свои плейлисты M3U / Xtream Codes (а для быстрой проверки встроен безопасный Демо-плейлист открытых потоков).

---

## Выбор режима: ТВ / Телефон / Автоопределение

- **При первом запуске** открывается мастер настройки (`SetupWizardActivity`), где можно выбрать:
  1. **Автоопределение (Рекомендуется)** — программа сама определяет Android TV / приставку (по `UI_MODE_TYPE_TELEVISION`, `FEATURE_LEANBACK`, отсутствию сенсора) или смартфон/планшет.
  2. **Телевизор / Приставка (Пульт ДУ)** — 4-колоночный ТВ-интерфейс (боковое меню, категории, список/плитка каналов, панель EPG-предпросмотра справа), крупный фокус и полное управление с пульта.
  3. **Телефон / Планшет (Сенсор)** — компактная верхняя панель, горизонтальные чипы категорий, нижняя навигация, свайп-обновление, жесты яркости/громкости/перемотки и режим **Картинка в картинке (PiP)**.
- **Переключение в любой момент**: кнопка **«Режим: ТВ / Телефон / Авто»** прямо в главном меню и в **Настройки → Устройство и интерфейс**.

## Возможности (аналог Televizo + расширенные функции)

### Плейлисты и контент
- Неограниченное количество плейлистов с быстрым переключением и включением/выключением.
- **M3U / M3U8 по ссылке (URL)** и **локальные файлы `.m3u` / `.m3u8`** (включая прямое открытие файла из проводника).
- **Xtream Codes API**: автоматическая загрузка **ТВ каналов (Live)**, **Фильмов (VOD)**, **Сериалов (сезоны и эпизоды)**, **EPG** и срока действия подписки.
- Индивидуальные настройки для каждого плейлиста: `User-Agent`, `Referer`, ссылка EPG, смещение часового пояса EPG, тип и глубина архива, автообновление (при запуске / каждые N часов / вручную).
- **Избранное (★)**, **Недавние (История с сохранением позиции VOD)**, **Поиск**, сортировка, скрытие и блокировка отдельных каналов и категорий.

### Телепрограмма (EPG) и Архив (Catch-up)
- Потоковый парсер **XMLTV** с автоматической поддержкой сжатых **`.xml.gz`** и обычных **`.xml`** файлов.
- Полоса прогресса текущей передачи и показ следующей передачи в списке каналов и в плеере.
- Отдельный экран **Телепрограмма (Вчера / Сегодня / Завтра)** и быстрая выдвижная панель EPG прямо поверх видео.
- Воспроизведение **Архива (Catch-up)** в форматах `default`, `shift`, `append`, `flussonic`, `flussonic-ts`, `xc` (Xtream Codes) с перемоткой и возвратом в прямой эфир в 1 нажатие.

### Двойной движок воспроизведения
- **Media3 ExoPlayer** (по умолчанию) — максимально быстрое переключение каналов, HLS/DASH/RTSP/MPEG-TS, выбор аудиодорожек и субтитров.
- **LibVLC 3.6.2** — воспроизведение любых потоков и кодеков (UDP/RTP/RTMP/MMS, AC3/EAC3/DTS, MPEG-2, деинтерлейсинг 1080i, программное усиление громкости до **200%**).
- **Автопереключение на LibVLC** при ошибке потока в ExoPlayer + автоматическое переподключение при обрыве сети.
- **Внешний плеер** — открытие потока в VLC, MX Player, ALEXVID и др.

### Управление с пульта ДУ (в плеере)
| Кнопка пульта | Действие по умолчанию (настраивается в Настройках) |
|---|---|
| `Вверх` / `Вниз` или `CH+` / `CH-` | Переключение каналов (можно инвертировать или назначить список/громкость) |
| `Влево` | Выдвижной список каналов поверх видео |
| `Вправо` | Выдвижная телепрограмма и Архив канала поверх видео |
| `OK / Центр` | Показать/скрыть инфо-панель (OSD) с часами, EPG и кнопками |
| **Удержание `OK`** или `MENU` | Быстрое меню (Аудио, Субтитры, Масштаб, Движок, Скорость, Сон, Избранное) |
| `0`–`9` | Прямой набор номера канала (цифра `0` — возврат на предыдущий канал) |
| `GUIDE` | Открыть телепрограмму / Архив |
| `Назад` | Закрыть панель / двойное нажатие для выхода |

### 8 разделов настроек (50+ параметров)
1. **Устройство и интерфейс** (Режим ТВ/Телефон/Авто, 4 темы, 5 акцентов, вид списка/плитки/компактный, размер шрифта 85–130%, логотипы, номера, часы, таймер OSD, стартовый экран).
2. **Плейлисты** (добавление, обновление, демо-плейлист).
3. **Телепрограмма (EPG)** (источники XMLTV, смещение `−12ч..+12ч`, интервал, глубина хранения архива, очистка).
4. **Плеер и декодер** (ExoPlayer / LibVLC / Внешний, автофолбэк, HW/CPU ускорение, сетевой буфер 0.5–12с, автопереподключение, масштаб, деинтерлейсинг, языки аудио/субтитров, Passthrough, усиление звука 200%, PiP, User-Agent).
5. **Пульт ДУ и жесты** (переназначение всех стрелок и OK, инверсия каналов, ввод 0–9, двойной Назад, жесты телефона).
6. **Родительский контроль** (4-значный PIN, автоблокировка категорий `18+`/`Adult`/`XXX`, скрытие заблокированных каналов, защита Настроек и Плейлистов).
7. **Сон и автозапуск** (Таймер сна 15–120 мин, автозапуск при включении ТВ-приставки, не выключать экран).
8. **Копия, кэш и о программе** (Экспорт/Импорт полной резервной копии в JSON, размер и очистка кэша, очистка истории, сброс настроек).

## Сборка APK (GitHub Actions или Android Studio)

В папке `.github/workflows/build-apk.yml` настроен готовый CI-workflow. При создании репозитория на GitHub и пуше в `main` автоматически соберутся и опубликуются в **Releases** и **Artifacts** готовые APK:
- `E-Televizor-arm64-v8a.apk` — для современных смартфонов и 64-битных ТВ-приставок.
- `E-Televizor-armeabi-v7a.apk` — для 32-битных Android TV и бюджетных приставок.
- `E-Televizor-universal.apk` — универсальный APK для любых устройств Android.
